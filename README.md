# Приложение «Ilona» — как выложить, чтобы открывать с любого телефона

1. На github.com нажми **New repository** → имя, например `plan`, тип **Public** → Create.
2. **Add file → Upload files** → перетащи все файлы из этого архива (index.html, *.js, иконки, manifest, sw.js) → **Commit**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение откроется по адресу `https://<твой-логин>.github.io/plan/`.
5. Открой адрес на телефоне, введи код и установи приложение на экран (iPhone — Safari → «Поделиться» → «На экран „Домой“», Android — Chrome → ⋮ → «Установить приложение»).
6. Девушке: в приложении «Ещё → Настройки → Приложение на телефоне девушки» появятся ссылка и QR-код. Пусть она его отсканирует.

Код репозитория публичный, но твои данные (цели, деньги, дневник) в него не попадают: они хранятся только в памяти браузера на каждом телефоне.
